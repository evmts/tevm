# Receipts & logs

ZEVM indexes transaction receipts and event logs as blocks are mined. Query them through viem public actions, JSON-RPC, or WebSocket subscriptions over `@tevm/server`.

## Query a receipt and logs

```ts
import { createMemoryClient, parseEther, PREFUNDED_ACCOUNTS } from 'tevm'

const client = createMemoryClient({ mining: { auto: false } })
try {
  const { txHash } = await client.tevmCall({
    from: PREFUNDED_ACCOUNTS[0].address,
    to: '0x1111111111111111111111111111111111111111',
    value: parseEther('1'),
    addToMempool: true,
  })

  // Receipt is unavailable while the transaction is pending
  await client.tevmMine({ blocks: 1 })

  const receipt = await client.getTransactionReceipt({ hash: txHash! })
  const logs = await client.getLogs({ fromBlock: 0n, toBlock: 'latest' })
  console.log(receipt.status, receipt.gasUsed, logs.length)
} finally {
  await client.tevmClose()
}
```

## Live log streams

When serving a client via `createServer(client)` from `tevm/server`, WebSocket clients can subscribe directly to `eth_subscribe` with `['logs', { address, topics }]`.

See [HTTP, WebSocket & IPC server](/api/server) and [JSON-RPC reference](/api/json-rpc).
