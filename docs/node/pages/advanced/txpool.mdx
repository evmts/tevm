# Transaction pool

ZEVM manages pending and queued transactions natively. When `mining: { auto: false }`, submitted transactions stay in the pool until mined with `tevmMine()` or `mine()`.

## Inspecting pending transactions

```ts
import { createMemoryClient, parseEther, PREFUNDED_ACCOUNTS } from 'tevm'

const client = createMemoryClient({ mining: { auto: false } })
try {
  await client.tevmCall({
    from: PREFUNDED_ACCOUNTS[0].address,
    to: '0x1111111111111111111111111111111111111111',
    value: parseEther('1'),
    addToMempool: true,
  })

  const status = await client.transport.tevm.request({ method: 'txpool_status' })
  const content = await client.transport.tevm.request({ method: 'txpool_content' })
  console.log({ status, content })

  await client.tevmMine({ blocks: 1 })
} finally {
  await client.tevmClose()
}
```

Supported RPC methods: `txpool_status`, `txpool_content`, `txpool_contentFrom`, `txpool_inspect`.

See [Mining & block production](/core/mining-modes) and [JSON-RPC reference](/api/json-rpc).
