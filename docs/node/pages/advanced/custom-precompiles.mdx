# Custom precompiles

JavaScript `customPrecompiles` (`definePrecompile`) were tied to the removed EthereumJS interpreter and are not supported in the native Zig ZEVM engine.

## Supported alternatives

- **Override contract behavior for one call:** use `stateOverride` in `tevmCall` / `eth_call` to swap bytecode or storage slots without mutating chain state.
- **Inject mock contract bytecode:** use `tevmSetAccount({ address, deployedBytecode, storage })` or `client.setCode({ address, bytecode })`.
- **Inspect execution:** use native `debug_traceCall` (Guillotine Mini opcode tracer) instead of JS precompile hooks.

See [Call, contract & deploy](/api/tevm-call) and [Migrating from the JS engine](/core/migration-from-js-engine).
