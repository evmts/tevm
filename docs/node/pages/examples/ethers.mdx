# Ethers v6 cookbook

Use `TevmProvider` from `@tevm/ethers` to pair ethers v6 `Wallet`, `ContractFactory`, and `Contract` instances with Tevm's native in-process engine.

## Install

```bash
pnpm add tevm viem ethers@6 @tevm/ethers
```

## Complete example: Fund, deploy, write, and verify

```ts
import { TevmProvider } from '@tevm/ethers'
import { ContractFactory, Wallet, formatEther, parseEther } from 'ethers'
import { getAddress } from 'tevm'

const counterAbi = [
  'function number() view returns (uint256)',
  'function increment() public',
] as const

const counterBytecode =
  '0x608060405234801561001057600080fd5b5060f78061001f6000396000f3fe6080604052348015600f57600080fd5b5060043610603c5760003560e01c80633fb5c1cb1460415780638381f58a146053578063d09de08a14606d575b600080fd5b6051604c3660046083565b600055565b005b605b60005481565b60405190815260200160405180910390f35b6051600080549080607c83609b565b9190505550565b600060208284031215609457600080fd5b5035919050565b60006001820160ba57634e487b7160e01b600052601160045260246000fd5b506001019056fea2646970667358221220d5fb46adf6ce0cfd90fa4324ffd8c48b0fc6fb6c4cac9ca2c69c97e25f355c9d64736f6c63430008110033'

const provider = await TevmProvider.createMemoryProvider({
  mining: { auto: false },
})

try {
  // 1. Create a fresh signer and fund it via provider.tevm
  const signer = Wallet.createRandom().connect(provider)
  await provider.tevm.setBalance({
    address: getAddress(signer.address),
    value: parseEther('10'),
  })
  console.log('Balance:', formatEther(await provider.getBalance(signer.address)), 'ETH')

  // 2. Deploy the contract and mine the deployment block
  const factory = new ContractFactory(counterAbi, counterBytecode, signer)
  const deployment = await factory.deploy()
  await provider.tevm.mine({ blocks: 1 })

  const counter = await deployment.waitForDeployment()
  console.log('Deployed at:', await counter.getAddress())
  console.log('Initial count:', await counter.getFunction('number')()) // 0n

  // 3. Call increment(), mine, and read updated state
  const tx = await counter.getFunction('increment')()
  await provider.tevm.mine({ blocks: 1 })
  await tx.wait()

  console.log('Updated count:', await counter.getFunction('number')()) // 1n
} finally {
  provider.destroy()
}
```

## Automining mode

If you omit `mining: { auto: false }`, automining is enabled by default — you do not need to call `provider.tevm.mine()` after `factory.deploy()` or `counter.increment()`.

## Wrapping an existing `MemoryClient`

If you already created a `MemoryClient` (for example, shared with viem or `@tevm/server`), pass it straight to `new TevmProvider(client)`:

```ts
import { TevmProvider } from '@tevm/ethers'
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
await client.tevmReady()
const provider = new TevmProvider(client)

// provider.destroy() closes the underlying client as well
provider.destroy()
```
