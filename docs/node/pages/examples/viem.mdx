# Viem cookbook

Every snippet on this page runs directly against `createMemoryClient()` (or a custom viem client with `createTevmTransport()`).

## Batteries-included vs. tree-shakeable

:::code-group

```ts [Batteries-included]
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
try {
  const blockNumber = await client.getBlockNumber()
  const blob = await client.tevmDumpState()
  console.log(blockNumber, blob.slice(0, 18))
} finally {
  await client.tevmClose()
}
```

```ts [Tree-shakeable]
import { createTevmTransport, tevmDumpState } from 'tevm'
import { createClient } from 'viem'
import { getBlockNumber } from 'viem/actions'

const client = createClient({
  cacheTime: 0,
  transport: createTevmTransport(),
})

try {
  const blockNumber = await getBlockNumber(client)
  const blob = await tevmDumpState(client)
  console.log(blockNumber, blob.slice(0, 18))
} finally {
  await client.transport.tevm.close()
}
```

:::

## Impersonating any address

Send transactions from any address (such as a mainnet whale or multisig) without knowing its private key:

```ts
import { createMemoryClient, parseEther } from 'tevm'

const client = createMemoryClient()
try {
  const whale = '0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045'
  const receiver = '0x1111111111111111111111111111111111111111'

  await client.setBalance({ address: whale, value: parseEther('10') })
  await client.impersonateAccount({ address: whale })

  const hash = await client.sendTransaction({
    account: whale,
    to: receiver,
    value: parseEther('1'),
  })

  const receipt = await client.getTransactionReceipt({ hash })
  console.log(receipt.status, await client.getBalance({ address: receiver }))

  await client.stopImpersonatingAccount({ address: whale })
} finally {
  await client.tevmClose()
}
```

## Signing with a custom private key

```ts
import { createMemoryClient, parseEther } from 'tevm'
import { privateKeyToAccount } from 'viem/accounts'

const account = privateKeyToAccount(
  '0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80',
)

const client = createMemoryClient({ account })
try {
  const hash = await client.sendTransaction({
    to: '0x1111111111111111111111111111111111111111',
    value: parseEther('0.5'),
  })
  const receipt = await client.getTransactionReceipt({ hash })
  console.log('Mined in block:', receipt.blockNumber)
} finally {
  await client.tevmClose()
}
```

## Cloning state across two clients

Export ZEVM's opaque hex blob from one client and load it into a second independent client:

```ts
import { createMemoryClient, parseEther } from 'tevm'

const clientA = createMemoryClient()
const clientB = createMemoryClient()

try {
  const addr = '0x2222222222222222222222222222222222222222'
  await clientA.tevmDeal({ address: addr, amount: parseEther('5') })

  const stateBlob = await clientA.tevmDumpState()
  await clientB.tevmLoadState(stateBlob)

  console.log(await clientB.getBalance({ address: addr })) // 5000000000000000000n
} finally {
  await clientA.tevmClose()
  await clientB.tevmClose()
}
```

## Composing `MemoryClient` manually

Under the hood, `createMemoryClient()` is five lines of viem composition:

```ts
import { createTevmTransport } from 'tevm'
import { tevmViemActions } from 'tevm/memory-client'
import { createClient, publicActions, testActions, walletActions } from 'viem'
import { foundry } from 'viem/chains'

const client = createClient({
  chain: foundry,
  cacheTime: 0,
  transport: createTevmTransport(),
})
  .extend(publicActions)
  .extend(walletActions)
  .extend(testActions({ mode: 'anvil' }))
  .extend(tevmViemActions())
```
