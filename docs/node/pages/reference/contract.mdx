# `@tevm/contract`

Subpath: `tevm/contract` (also re-exported from `tevm`).

Builds typed contract objects whose `read.*`, `write.*`, `events.*`, and `deploy(...)` methods produce parameter objects directly consumable by viem and Tevm actions.

## Exports

| Symbol | Description |
| --- | --- |
| `createContract(params)` | Create a typed `Contract` from an ABI (or `humanReadableAbi`), optional `address`, `bytecode`, and `deployedBytecode`. |
| `SimpleContract` | Minimal `uint256` getter/setter fixture (`get()`, `set(uint256)`). |
| `ERC20` | Standard ERC-20 contract fixture with ABI and bytecode. |
| `ERC721` | Standard ERC-721 contract fixture with ABI and bytecode. |
| `ErrorContract` | Fixture exposing custom revert cases for error-handling tests. |
| `AdvancedContract` | Complex Solidity types fixture (structs, arrays, events). |

## Example

```ts
import { createContract, createMemoryClient, PREFUNDED_ACCOUNTS } from 'tevm'
import { SimpleContract } from 'tevm/contract'

const custom = createContract({
  name: 'Counter',
  humanReadableAbi: [
    'function get() view returns (uint256)',
    'function set(uint256 value)',
  ],
})

const client = createMemoryClient({ account: PREFUNDED_ACCOUNTS[0] })
try {
  const hash = await client.deployContract(SimpleContract.deploy(10n))
  const receipt = await client.getTransactionReceipt({ hash })
  const deployed = custom.withAddress(receipt.contractAddress!)

  console.log(await client.readContract(deployed.read.get())) // 10n
} finally {
  await client.tevmClose()
}
```
