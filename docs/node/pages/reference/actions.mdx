# `@tevm/actions`

Subpath: `tevm/actions` (also re-exported from `tevm`).

Browser-safe, tree-shakeable functions that operate on any `RpcClient` (`{ request(req: EngineRequest): Promise<JsonValue> }`) — including `ZevmEngine`, `MemoryClient`, or a viem HTTP/WebSocket client.

## Exports

| Function | Signature | Native RPC method(s) |
| --- | --- | --- |
| `tevmCall` | `(client, params: CallParams) => Promise<CallResult>` | `eth_call`, or `eth_sendTransaction` (+ `evm_mine` when `addToBlockchain`) |
| `tevmContract` | `(client, params) => Promise<CallResult & { data? }>` | ABI-encodes and calls `tevmCall`; decodes `data` on read calls |
| `tevmDeploy` | `(client, params: DeployParams) => Promise<CallResult & { createdAddress? }>` | Encodes deploy data and calls `tevmCall` (`addToBlockchain: !addToMempool`) |
| `tevmGetAccount` | `(client, { address }) => Promise<GetAccountResult>` | `zevm_getAccount` (decodes `balance` and `nonce` to `bigint`) |
| `tevmSetAccount` | `(client, params: SetAccountParams) => Promise<void>` | Sequential `anvil_setBalance`, `anvil_setNonce`, `anvil_setCode`, `anvil_setStorageAt` |
| `tevmDeal` | `(client, { address, amount }) => Promise<JsonValue>` | `anvil_setBalance` |
| `tevmMine` | `(client, { blocks?, interval? }?) => Promise<JsonValue>` | `anvil_mine` (defaults `blocks = 1`, `interval = 1`) |
| `tevmDumpState` | `(client) => Promise<Hex>` | `anvil_dumpState` (returns ZEVM hex state blob) |
| `tevmLoadState` | `(client, state: Hex) => Promise<JsonValue>` | `anvil_loadState` |

## Example

```ts
import { createZevmEngine } from 'tevm/node'
import { tevmCall, tevmDeal, tevmGetAccount } from 'tevm/actions'

const engine = createZevmEngine()
try {
  const address = '0x0000000000000000000000000000000000000123'
  await tevmDeal(engine, { address, amount: 42n })
  const account = await tevmGetAccount(engine, { address })
  const call = await tevmCall(engine, { to: address })
  console.log(account.balance, call.rawData) // 42n '0x'
} finally {
  await engine.close()
}
```
