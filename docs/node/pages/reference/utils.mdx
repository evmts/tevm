# `@tevm/utils`

Subpath: `tevm/utils` (also re-exported from `tevm`).

Re-exports commonly used viem ABI, hex, byte, RLP, and signing helpers alongside Tevm's deterministic dev accounts.

## Key exports

- **Prefunded accounts:** `PREFUNDED_ACCOUNTS`, `PREFUNDED_PRIVATE_KEYS`, `PREFUNDED_PUBLIC_KEYS`, `PREFUNDED_SEED`
- **Units & addresses:** `parseEther`, `formatEther`, `parseGwei`, `formatGwei`, `getAddress`, `isAddress`
- **Hex & bytes:** `toHex`, `fromHex`, `toBytes`, `fromBytes`, `bytesToHex`, `hexToBytes`, `bytesToBigInt`, `hexToBigInt`, `numberToHex`, `stringToHex`, `hexToString`, `isHex`, `isBytes`
- **ABI & hashing:** `parseAbi`, `formatAbi`, `encodeFunctionData`, `decodeFunctionResult`, `encodeDeployData`, `encodeAbiParameters`, `decodeAbiParameters`, `encodeErrorResult`, `decodeErrorResult`, `encodeEventTopics`, `decodeEventLog`, `encodePacked`, `keccak256`
- **RLP & signing:** `toRlp`, `fromRlp`, `serializeTransaction`, `mnemonicToAccount`, `signMessage`, `hashMessage`, `verifyMessage`, `recoverAddress`, `recoverMessageAddress`

## Example

```ts
import { formatEther, parseEther, PREFUNDED_ACCOUNTS } from 'tevm/utils'

console.log(PREFUNDED_ACCOUNTS[0].address)
console.log(formatEther(parseEther('1.5'))) // '1.5'
```
