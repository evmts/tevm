# `@tevm/common`

Subpath: `tevm/common`.

Re-exports all chain definitions from `viem/chains`, the `Common` type alias (`Chain`), and `tevmDefault` (an alias for viem's `foundry` chain, ID `31337`).

## Exports

```ts
export type { Chain as Common } from 'viem'
export * from 'viem/chains'
export { foundry as tevmDefault } from 'viem/chains'
```

## Example

```ts
import { createMemoryClient } from 'tevm'
import { mainnet, optimism, tevmDefault } from 'tevm/common'

const local = createMemoryClient({ common: tevmDefault })
const opFork = createMemoryClient({
  chainId: optimism.id,
  common: optimism,
  fork: { url: 'https://mainnet.optimism.io' },
})
```

Pass `chainId` explicitly alongside `common` whenever the native ZEVM engine's `eth_chainId` should match a non-default network (`mainnet.id`, `optimism.id`, `base.id`, etc.).
