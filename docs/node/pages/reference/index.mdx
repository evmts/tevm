# Package reference

Every active package is also re-exported through the umbrella `tevm` package.

| Package | Subpath | Summary |
| --- | --- | --- |
| [`@tevm/memory-client`](/reference/memory-client) | `tevm/memory-client` | Viem-compatible in-process client (`createMemoryClient`, `createTevmTransport`, `tevmViemActions`) |
| [`@tevm/node`](/reference/node) | `tevm/node` | Native ZEVM Node-API wrapper (`createZevmEngine`, `createTevmNode`, `NativeRpcError`) |
| [`@tevm/actions`](/reference/actions) | `tevm/actions` | Browser-safe typed RPC helpers (`tevmCall`, `tevmContract`, `tevmDeploy`, `tevmDeal`, `tevmMine`, …) |
| [`@tevm/server`](/reference/server) | `tevm/server` | HTTP, WebSocket, Unix IPC, Express, and Next.js JSON-RPC servers |
| [`@tevm/contract`](/reference/contract) | `tevm/contract` | `createContract` and bundled contract fixtures (`SimpleContract`, `ERC20`, `ERC721`, `ErrorContract`) |
| [`@tevm/common`](/reference/common) | `tevm/common` | Viem chain presets and `tevmDefault` (`foundry`) |
| [`@tevm/utils`](/reference/utils) | `tevm/utils` | ABI/hex/RLP helpers and `PREFUNDED_ACCOUNTS` |
| [Bundler plugins](/reference/bundler) | `tevm/bundler/*` | Direct `.sol` import plugins for Vite, Rollup, esbuild, Webpack, Rspack, and Bun |
