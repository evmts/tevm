# `@tevm/memory-client`

Subpath: `tevm/memory-client` (also re-exported from `tevm`).

Wraps `ZevmEngine` as a viem transport (`cacheTime: 0`) and attaches viem `publicActions`, `walletActions`, `testActions({ mode: 'anvil' })`, and `tevmViemActions()`.

## Exports

| Symbol | Signature | Description |
| --- | --- | --- |
| `createMemoryClient` | `(options?: MemoryClientOptions) => MemoryClient` | Batteries-included viem client backed by an isolated (or supplied) native ZEVM engine. |
| `createTevmTransport` | `(options?: ZevmEngineOptions & { engine?: ZevmEngine }) => Transport` | Tree-shakeable viem transport backed by `ZevmEngine` (exposed on `client.transport.tevm`). |
| `tevmViemActions` | `() => (client) => TevmViemActions` | Viem client extension attaching `tevmReady`, `tevmClose`, `tevmCall`, `tevmContract`, `tevmDeploy`, `tevmSetAccount`, `tevmGetAccount`, `tevmMine`, `tevmDumpState`, `tevmLoadState`, `tevmDeal`. |
| `tevmReady` | `(client) => Promise<void>` | Awaits initialization of `client.transport.tevm`. |

## Options (`MemoryClientOptions`)

```ts
export type MemoryClientOptions = ZevmEngineOptions & {
  engine?: ZevmEngine
  common?: Chain
  account?: Account | Hex
  name?: string
  key?: string
}
```

## Example

```ts
import { createMemoryClient } from 'tevm/memory-client'

const client = createMemoryClient({
  chainId: 31337,
  mining: { auto: true },
})

try {
  await client.tevmReady()
  console.log(await client.getChainId(), await client.getBlockNumber())
} finally {
  await client.tevmClose()
}
```
