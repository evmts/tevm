# Accounts, storage & snapshots

Voltaire and ZEVM own all Ethereum state inside the native engine. Tevm exposes three complementary tools for manipulating that state:

1. **Account and storage helpers** — `tevmGetAccount`, `tevmSetAccount`, `tevmDeal`, plus viem Anvil test actions (`setBalance`, `setCode`, `setNonce`, `setStorageAt`).
2. **In-process snapshots** — `snapshot()` / `revert({ id })` (`evm_snapshot` / `evm_revert`).
3. **Portable state blobs** — `tevmDumpState()` / `tevmLoadState(blob)` (`anvil_dumpState` / `anvil_loadState`).

## Reading and writing accounts

```ts
import { createMemoryClient, toHex } from 'tevm'

const client = createMemoryClient()

try {
  const address = '0x0000000000000000000000000000000000000123'
  const slot0 = toHex(0n, { size: 32 })
  const value9 = toHex(9n, { size: 32 })

  await client.tevmSetAccount({
    address,
    balance: 42n,
    nonce: 2n,
    deployedBytecode: '0x602a60005260206000f3',
    storage: { [slot0]: value9 },
  })

  const account = await client.tevmGetAccount({ address })
  console.log({
    balance: account.balance, // 42n
    nonce: account.nonce, // 2n
    code: account.deployedBytecode, // '0x602a60005260206000f3'
    slot0: await client.getStorageAt({ address, slot: slot0 }), // 0x00...09
  })
} finally {
  await client.tevmClose()
}
```

Unspecified fields in `tevmSetAccount` are preserved. To update only a balance, `tevmDeal({ address, amount })` or viem's `setBalance({ address, value })` is shorter:

```ts
await client.tevmDeal({ address, amount: 100n })
```

<WatchOut title="Multi-field tevmSetAccount calls are not atomic">
Under the hood, `tevmSetAccount` issues separate native RPC calls for each supplied field (`anvil_setBalance`, `anvil_setNonce`, `anvil_setCode`, and one `anvil_setStorageAt` per slot). If a later setter fails, earlier setters have already mutated state. Wrap multi-field edits in `snapshot()` / `revert()` if you need all-or-nothing rollback.
</WatchOut>

### In-process rollback (`snapshot` / `revert`)

Snapshots rewind a single engine's state, blocks, and timestamps back to the exact point the snapshot was taken:

```ts
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()

try {
  const target = '0x3333333333333333333333333333333333333333'
  const snapshotId = await client.snapshot()

  await client.setBalance({ address: target, value: 999n })
  console.log(await client.getBalance({ address: target })) // 999n

  await client.revert({ id: snapshotId })
  console.log(await client.getBalance({ address: target })) // 0n
} finally {
  await client.tevmClose()
}
```

Reverting consumes `snapshotId`. If you run multiple tests against one client, take a fresh snapshot after each revert (for example in `beforeEach` / `afterEach`).

### Portable state blobs (`tevmDumpState` / `tevmLoadState`)

`tevmDumpState()` returns ZEVM's opaque hexadecimal state blob (`0x...`). Pass that hex string directly to `tevmLoadState(blob)` on another engine — or write it to disk to seed a future run:

```ts
import { createMemoryClient } from 'tevm'

const source = createMemoryClient()
const target = createMemoryClient()

try {
  const address = '0x0000000000000000000000000000000000000123'
  await source.tevmDeal({ address, amount: 99n })

  // Export opaque ZEVM hex blob
  const blob = await source.tevmDumpState()

  // Hydrate an independent engine
  await target.tevmLoadState(blob)
  console.log((await target.tevmGetAccount({ address })).balance) // 99n
} finally {
  await source.tevmClose()
  await target.tevmClose()
}
```

<WatchOut title="Opaque hex blob, not a JSON account map">
`tevmDumpState()` returns a hex string (`Hex`) encoded by ZEVM — not the old `{ state: Record<Address, Account> }` object from pre-migration JS releases. Pass the hex string straight into `client.tevmLoadState(blob)` (not `{ state: blob }`).
</WatchOut>

## Wire vs. host types

| Operation | Balance / Nonce type | Storage slot format |
| --- | --- | --- |
| `tevmGetAccount` / `tevmSetAccount` / `tevmDeal` | `bigint` | 32-byte hex string (or minimal hex key) |
| viem `getBalance` / `setBalance` / `getStorageAt` | `bigint` | 32-byte hex string |
| Raw `engine.request({ method: 'eth_getBalance', ... })` | Hex quantity (`'0x2a'`) | Hex quantity / 32-byte hex |
