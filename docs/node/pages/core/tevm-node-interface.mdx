# Engine API (`ZevmEngine`)

`createZevmEngine` (also exported as `createTevmNode`) is the lowest-level JavaScript interface in Tevm. Use `createMemoryClient` for application and test code; use `createZevmEngine` directly when building custom RPC servers, proxies, CLI harnesses, or protocol tooling.

## Interface

```ts
export type JsonValue =
  | null
  | boolean
  | number
  | string
  | JsonValue[]
  | { [key: string]: JsonValue }

export type EngineRequest = {
  method: string
  params?: JsonValue[]
}

export type ZevmEngineOptions = {
  /** Unsigned safe integer chain ID. Defaults to 31337. */
  chainId?: number
  /** Automine defaults to true. Interval is whole seconds; 0 disables the timer. */
  mining?: { auto?: boolean; interval?: number }
  /** Fork upstream state into a local chain at height 0. */
  fork?: { url: string; blockNumber?: number }
}

export type ZevmEngine = {
  events: EventEmitter
  ready: () => Promise<void>
  request: (request: EngineRequest) => Promise<JsonValue>
  rpc: (json: string) => Promise<string | null>
  close: () => Promise<void>
}
```

## `request()` vs. `rpc()`

- **`request({ method, params })`** wraps your call in a JSON-RPC 2.0 envelope, parses the native response, returns `response.result`, and throws `NativeRpcError` if the native dispatcher returns an error object.
- **`rpc(jsonString)`** passes raw JSON-RPC wire text straight to ZEVM and returns the exact serialized JSON response string — or `null` for notifications (requests without an `id`). Use `rpc()` for HTTP/WebSocket/IPC servers, JSON-RPC batches, and exact wire conformance checks.

```ts
import { createZevmEngine, NativeRpcError } from 'tevm/node'

const engine = createZevmEngine({ mining: { auto: false } })

try {
  await engine.ready()

  // Single typed request
  const chainId = await engine.request({ method: 'eth_chainId' })
  console.log(chainId) // '0x7a69'

  // Raw JSON-RPC batch
  const batchJson = await engine.rpc(
    JSON.stringify([
      { jsonrpc: '2.0', id: 1, method: 'eth_blockNumber' },
      { jsonrpc: '2.0', id: 2, method: 'eth_accounts' },
    ]),
  )
  console.log(JSON.parse(batchJson!))

  // JSON-RPC notification (no id) -> returns null
  const note = await engine.rpc(
    JSON.stringify({ jsonrpc: '2.0', method: 'eth_chainId' }),
  )
  console.log(note) // null

  // Structured native error
  try {
    await engine.request({ method: 'missing_method' })
  } catch (error) {
    if (error instanceof NativeRpcError) {
      console.log(error.code, error.message) // -32601 'Method not found'
    }
  }
} finally {
  await engine.close()
}
```

## Lifecycle events

`engine.events` is a Node.js `EventEmitter` that emits four events:

| Event | Payload | When it fires |
| --- | --- | --- |
| `request` | `EngineRequest` (`{ method, params? }`) | Immediately before `engine.request()` dispatches to native code |
| `response` | `{ request: EngineRequest; result: JsonValue }` | Immediately after `engine.request()` succeeds |
| `block` | Block header object (`eth_getBlockByNumber` result) | When block height advances — via explicit mining or background interval mining |
| `close` | *(none)* | Once, when `engine.close()` releases the native handle |

```ts
import { createZevmEngine } from 'tevm/node'

const engine = createZevmEngine({ mining: { auto: false } })
engine.events.on('block', (block) => console.log('Mined:', block.number))
engine.events.on('close', () => console.log('Engine closed'))

try {
  await engine.request({ method: 'evm_mine' })
} finally {
  await engine.close()
}
```

<UnderTheHood>
Calls to `request()`, `rpc()`, and `close()` execute sequentially through an internal FIFO promise queue. Concurrent `Promise.all([...])` mutations serialize cleanly without racing inside native memory.
</UnderTheHood>

<WatchOut title="Closed engines reject immediately">
`engine.close()` is idempotent and frees the native handle. Any subsequent `request()` or `rpc()` rejects with `Error('engine is closed')`.
</WatchOut>

## Error class: `NativeRpcError`

`NativeRpcError` extends `Error` with:

- `code: number` — exact JSON-RPC error code from ZEVM (for example `-32601` Method not found, `-32602` Invalid params, `-32000` Server error, or `3` for EVM execution reverts).
- `data?: JsonValue` — optional structured data (for example, raw revert bytes `'0xdeadbeef'` when `code === 3`).
