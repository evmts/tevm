# Account management

Three helpers manage account state directly over native RPC: `tevmGetAccount`, `tevmSetAccount`, and `tevmDeal`. All three are available on `createMemoryClient()` and as standalone functions in `tevm` and `tevm/actions`.

## Prefunded dev accounts

Every local chain initializes 10 standard Foundry/Anvil dev accounts with 10,000 ETH each. Import them from `tevm` (or `tevm/utils`):

```ts
import { PREFUNDED_ACCOUNTS, PREFUNDED_PRIVATE_KEYS } from 'tevm'

console.log(PREFUNDED_ACCOUNTS[0].address)
// 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266
```

You can also query managed accounts directly from the engine via `client.getAddresses()` or `eth_accounts`.

## `tevmSetAccount`

Updates any combination of `balance`, `nonce`, `deployedBytecode`, and `storage`. Omitted fields remain unchanged.

```ts
type SetAccountParams = {
  address: Address
  balance?: bigint
  nonce?: bigint
  deployedBytecode?: Hex
  storage?: Record<Hex, Hex>
}
```

```ts
import { createMemoryClient, parseEther, toHex } from 'tevm'

const client = createMemoryClient()
try {
  const address = '0x0000000000000000000000000000000000000123'

  await client.tevmSetAccount({
    address,
    balance: parseEther('10'),
    nonce: 3n,
    deployedBytecode: '0x602a60005260206000f3',
    storage: {
      [toHex(0n, { size: 32 })]: toHex(42n, { size: 32 }),
    },
  })
} finally {
  await client.tevmClose()
}
```

<WatchOut title="Not atomic across multiple fields">
`tevmSetAccount` calls `anvil_setBalance`, `anvil_setNonce`, `anvil_setCode`, and `anvil_setStorageAt` sequentially. If you need multi-field rollback on failure, take a snapshot with `const id = await client.snapshot()` first and call `await client.revert({ id })` in a `catch` block.
</WatchOut>

## `tevmGetAccount`

Calls `zevm_getAccount` and converts hex `balance` and `nonce` quantities to `bigint`:

```ts
type GetAccountResult = {
  address: Address
  balance: bigint
  nonce: bigint
  deployedBytecode: Hex
  storage: Record<Hex, Hex>
}
```

```ts
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
try {
  const address = '0x0000000000000000000000000000000000000123'
  await client.tevmDeal({ address, amount: 500n })

  const account = await client.tevmGetAccount({ address })
  console.log(account.balance, account.nonce, account.deployedBytecode)
  // 500n 0n '0x'
} finally {
  await client.tevmClose()
}
```

## `tevmDeal`

Shorthand for setting an account's native ETH balance via `anvil_setBalance`:

```ts
await client.tevmDeal({
  address: '0x0000000000000000000000000000000000000123',
  amount: parseEther('100'),
})
```

## Standalone usage over `ZevmEngine`

All three functions work directly with `createZevmEngine()` without constructing a viem client:

```ts
import { createZevmEngine, tevmDeal, tevmGetAccount, tevmSetAccount } from 'tevm'

const engine = createZevmEngine()
try {
  const address = '0x0000000000000000000000000000000000000123'
  await tevmSetAccount(engine, { address, nonce: 1n })
  await tevmDeal(engine, { address, amount: 42n })

  const account = await tevmGetAccount(engine, { address })
  console.log(account.balance, account.nonce) // 42n 1n
} finally {
  await engine.close()
}
```
