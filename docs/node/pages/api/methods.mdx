# Client methods map

`createMemoryClient()` combines five surfaces on one object. Every method talks to the same underlying `ZevmEngine` (`client.transport.tevm`).

## TEVM actions

Attached to `MemoryClient` and exported as standalone functions from `tevm` and `tevm/actions`:

| Method on `MemoryClient` | Standalone function | Purpose |
| --- | --- | --- |
| `client.tevmReady()` | `tevmReady(client)` | Wait for initial fork/mining configuration |
| `client.tevmClose()` | `engine.close()` | Release the native handle and stop interval timers |
| `client.tevmCall(params)` | `tevmCall(rpc, params)` | Simulate (`eth_call` + `stateOverride`) or submit a tx (`addToMempool` / `addToBlockchain`) |
| `client.tevmContract(params)` | `tevmContract(rpc, params)` | ABI-encoded call with typed return decoding |
| `client.tevmDeploy(params)` | `tevmDeploy(rpc, params)` | Deploy creation bytecode (+ optional `abi`/`args`), returning `createdAddress` |
| `client.tevmGetAccount({ address })` | `tevmGetAccount(rpc, { address })` | Read `balance` (`bigint`), `nonce` (`bigint`), `deployedBytecode`, `storage` |
| `client.tevmSetAccount(params)` | `tevmSetAccount(rpc, params)` | Set any subset of `balance`, `nonce`, `deployedBytecode`, `storage` |
| `client.tevmDeal({ address, amount })` | `tevmDeal(rpc, { address, amount })` | Set an account's ETH balance |
| `client.tevmMine({ blocks?, interval? })` | `tevmMine(rpc, params)` | Mine blocks with optional timestamp step in seconds |
| `client.tevmDumpState()` | `tevmDumpState(rpc)` | Export ZEVM's opaque hex state blob (`0x...`) |
| `client.tevmLoadState(blob)` | `tevmLoadState(rpc, blob)` | Hydrate a ZEVM state blob |

## Viem public actions

Standard read-only queries (`cacheTime: 0`):

- **Blocks & chain:** `getBlockNumber`, `getBlock`, `getChainId`, `getGasPrice`, `estimateFeesPerGas`
- **Accounts & storage:** `getBalance`, `getCode`, `getStorageAt`, `getTransactionCount`
- **Transactions & logs:** `getTransaction`, `getTransactionReceipt`, `waitForTransactionReceipt`, `getLogs`, `createEventFilter`, `getFilterChanges`
- **Contracts:** `call`, `readContract`, `simulateContract`, `estimateGas`, `estimateContractGas`, `multicall`

## Viem wallet actions

Transaction submission and signing (uses `options.account` if set):

- `getAddresses`, `sendTransaction`, `sendRawTransaction`, `writeContract`, `deployContract`, `signMessage`, `signTypedData`

## Viem test actions (`mode: 'anvil'`)

Direct chain and state manipulation:

- **Accounts:** `setBalance`, `setCode`, `setNonce`, `setStorageAt`, `impersonateAccount`, `stopImpersonatingAccount`
- **Mining & time:** `mine`, `setAutomine`, `setIntervalMining`, `setNextBlockTimestamp`, `increaseTime`, `setNextBlockBaseFeePerGas`, `setBlockGasLimit`
- **State:** `snapshot`, `revert`, `reset`, `dumpState`, `loadState`

## Low-level engine (`client.transport.tevm`)

Direct access to `ZevmEngine`:

| Member | Purpose |
| --- | --- |
| `request({ method, params })` | Serialized EIP-1193 call; throws `NativeRpcError` on failure |
| `rpc(jsonString)` | Raw JSON-RPC 2.0 string (batches, notifications, exact wire response) |
| `events` | `EventEmitter` emitting `request`, `response`, `block`, `close` |
| `ready()` | Initialization promise |
| `close()` | Idempotent native shutdown |
