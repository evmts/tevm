# Package overview

Most applications only need the umbrella `tevm` package alongside `viem`. Install individual `@tevm/*` packages only when building specialized adapters or minimizing dependencies.

```bash
pnpm add tevm viem
```

## `tevm` subpath exports

| Import path | Backing package | Purpose |
| --- | --- | --- |
| `tevm` | Umbrella | `createMemoryClient`, `createZevmEngine`, `createTevmNode`, `NativeRpcError`, `createContract`, standalone `tevm*` actions, viem helpers, `PREFUNDED_ACCOUNTS` |
| `tevm/node` | `@tevm/node` | Native ZEVM Node-API wrapper (`createZevmEngine`, `createTevmNode`, `NativeRpcError`, types) |
| `tevm/memory-client` | `@tevm/memory-client` | `createMemoryClient`, `createTevmTransport`, `tevmViemActions`, `tevmReady` |
| `tevm/actions` | `@tevm/actions` | Browser-safe typed RPC helpers (`tevmCall`, `tevmContract`, `tevmDeploy`, `tevmDeal`, `tevmGetAccount`, `tevmSetAccount`, `tevmMine`, `tevmDumpState`, `tevmLoadState`) |
| `tevm/server` | `@tevm/server` | `createServer` (HTTP + WS), `createIpcServer`, `createHttpHandler`, `createWebSocketServer`, `createExpressMiddleware`, `createNextApiHandler` |
| `tevm/http-client` | `@tevm/http-client` | `createHttpClient` for connecting to a running TEVM HTTP server |
| `tevm/common` | `@tevm/common` | Viem chain presets (`mainnet`, `optimism`, `arbitrum`, `base`, …) and `tevmDefault` (`foundry`) |
| `tevm/contract` | `@tevm/contract` | `createContract` plus bundled fixtures (`SimpleContract`, `ERC20`, `ERC721`, `ErrorContract`, `AdvancedContract`) |
| `tevm/predeploys` | `@tevm/predeploys` | `definePredeploy` for typed predeploy descriptors |
| `tevm/errors` | `@tevm/errors` | Structured JSON-RPC, EVM, and client error classes extending `BaseError` |
| `tevm/utils` | `@tevm/utils` | ABI/hex/RLP utilities, `PREFUNDED_ACCOUNTS`, `PREFUNDED_PRIVATE_KEYS`, `serializeToJson` |
| `tevm/bundler/*` | `@tevm/*-plugin` | Build-time Solidity plugins (`vite-plugin`, `rollup-plugin`, `esbuild-plugin`, `webpack-plugin`, `rspack-plugin`, `bun-plugin`, `base-bundler`, `compiler`, `config`, `solc`) |

## Standalone ecosystem packages

| Package | Purpose |
| --- | --- |
| `@tevm/ethers` | `TevmProvider` (`JsonRpcApiProvider` subclass wired directly to native `rpc()`) |
| `@tevm/viem` | `tevmViemExtension()` — attaches `client.tevm.*` helpers onto any viem public client (browser-safe) |
| `@tevm/mcp` | Stdio Model Context Protocol server giving AI coding agents 14 isolated EVM & Solidity tools |
| `@tevm/ts-plugin` | TypeScript language service plugin for `.sol` import resolution, typechecking, and NatSpec hover |
| `@tevm/cli` | `tevm` command-line tool (`call`, `contract`, `deploy`, `mine`, `serve`, `dump-state`, `load-state`, …) |

## Native engine dependency

`@tevm/node` loads `@evmts/zevm` (the native Zig Node-API addon combining ZEVM, Voltaire, and Guillotine Mini). There is no pure-JavaScript fallback engine; if the native addon is missing for your platform, `createZevmEngine()` throws immediately.
