# Tracing & engine events

Tevm exposes two observability surfaces:

1. **Opcode-level execution traces** via native `debug_traceCall` (executed in Guillotine Mini).
2. **Engine lifecycle events** (`request`, `response`, `block`, `close`) on `ZevmEngine.events`.

## Native opcode tracing (`debug_traceCall`)

<TracePipelineDiagram />

`debug_traceCall` runs a call inside Guillotine Mini's native tracer and returns structured pre-opcode execution steps — including failing and reverting calls.

### Supported tracer options

| Option | Type | Default | Effect |
| --- | --- | --- | --- |
| `disableStack` | `boolean` | `false` | Omit the EVM stack array from each step. |
| `enableMemory` | `boolean` | `false` | Include 32-byte memory words before each opcode. |
| `enableReturnData` | `boolean` | `false` | Include the active return-data buffer on each step. |
| `disableStorage` | `boolean` | `true` | Only `true` is supported (storage diffs are not recorded per step). |

### Example: Trace a contract call

```ts
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()

try {
  const target = '0x0000000000000000000000000000000000000123'
  // PUSH1 0x2a; PUSH1 0x00; MSTORE; PUSH1 0x20; PUSH1 0x00; RETURN
  await client.tevmSetAccount({
    address: target,
    deployedBytecode: '0x602a60005260206000f3',
  })

  const trace = (await client.transport.tevm.request({
    method: 'debug_traceCall',
    params: [
      { to: target },
      'latest',
      { enableMemory: true, enableReturnData: true },
    ],
  })) as {
    gas: number
    failed: boolean
    returnValue: string
    truncated: boolean
    structLogs: Array<{
      pc: number
      op: string
      gas: number
      gasCost: number
      depth: number
      stack: string[]
      memory?: string[]
      returnData?: string
    }>
  }

  console.log({
    gas: trace.gas,
    failed: trace.failed,
    returnValue: trace.returnValue,
    truncated: trace.truncated,
    opcodes: trace.structLogs.map((s) => `${s.pc}:${s.op}(-${s.gasCost})`),
  })
  // opcodes: ['0:PUSH1(-3)', '2:PUSH1(-3)', '4:MSTORE(-6)', '5:PUSH1(-3)', '7:PUSH1(-3)', '9:RETURN(-0)']
} finally {
  await client.tevmClose()
}
```

### Trace payload fields

| Field | Type | Description |
| --- | --- | --- |
| `gas` | `number` | Total gas used by the traced call (including intrinsic gas). |
| `failed` | `boolean` | `true` if the call reverted or hit an EVM exception. |
| `returnValue` | `Hex` | Raw return data (or revert payload when `failed` is `true`). |
| `truncated` | `boolean` | `true` if execution exceeded the 100,000-step native retention cap. |
| `structLogs` | `Array<StructLog>` | Per-opcode trace entries (`pc`, `op`, `gas`, `gasCost`, `depth`, `stack`, optional `memory`, optional `returnData`). |

<WatchOut title="Current native tracer bounds">
`debug_traceCall` retains at most **100,000 steps** and sets `truncated: true` when clipped. Custom JS tracer programs and historical `debug_traceTransaction` replay are not supported by the native tracer.
</WatchOut>

## Engine lifecycle events (`engine.events`)

Access the engine's `EventEmitter` via `client.transport.tevm.events` (or `engine.events` when using `createZevmEngine`):

```ts
import { createMemoryClient } from 'tevm'

const client = createMemoryClient({ mining: { auto: false } })
const { events } = client.transport.tevm

events.on('request', (req) => console.log('->', req.method))
events.on('response', ({ request }) => console.log('<-', request.method))
events.on('block', (block) => console.log('block mined:', block.number))
events.on('close', () => console.log('engine closed'))

try {
  await client.tevmMine({ blocks: 1 })
} finally {
  await client.tevmClose()
}
```

| Event | Fires when |
| --- | --- |
| `request` | Before `engine.request()` dispatches to ZEVM. |
| `response` | After `engine.request()` resolves. |
| `block` | Whenever chain height advances — including autonomous blocks mined on the native interval thread. |
| `close` | Once when `tevmClose()` / `engine.close()` frees the native handle. |

<UnderTheHood>
To observe interval-mined blocks without polling in user code, `ZevmEngine` runs an unreferenced 50 ms check only while at least one `'block'` listener is registered, and clears it as soon as the last `'block'` listener is removed or the engine closes.
</UnderTheHood>
