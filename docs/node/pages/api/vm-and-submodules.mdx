# VM & submodules

Tevm's former JavaScript-implemented submodules (`@tevm/vm`, `@tevm/evm`, `@tevm/state`, `@tevm/blockchain`, `@tevm/tx`, `@tevm/txpool`, `@tevm/receipt-manager`) were replaced by a unified native Zig engine loaded via Node-API.

<ArchitectureDiagram />

## Component mapping

| Legacy JS submodule | Native owner | Host access |
| --- | --- | --- |
| `@tevm/evm` / `@tevm/vm` | Guillotine Mini + ZEVM | `tevmCall`, `tevmContract`, `tevmDeploy`, `debug_traceCall` |
| `@tevm/state` | Voltaire + ZEVM | `tevmGetAccount`, `tevmSetAccount`, `tevmDumpState`, `tevmLoadState`, `snapshot` / `revert` |
| `@tevm/blockchain` / `@tevm/block` | ZEVM | `getBlock`, `getBlockNumber`, `tevmMine`, `engine.events.on('block', ...)` |
| `@tevm/txpool` | ZEVM | `txpool_status`, `txpool_content`, `txpool_contentFrom`, `txpool_inspect` |
| `@tevm/receipt-manager` | ZEVM | `getTransactionReceipt`, `eth_getBlockReceipts`, `getLogs`, WebSocket `eth_subscribe` |

See [Architecture](/introduction/architecture-overview) and [Migrating from the JS engine](/core/migration-from-js-engine).
