# TEVM Node Documentation (`node.tevm.sh`)

Built with [Vocs](https://vocs.dev). `pnpm run build:app` runs `vocs build` followed by `scripts/factory/emit-docs-markdown.mjs` to emit clean Markdown (`.md`) mirrors of every documentation page, the Obsidian Engineering Wiki (`/wiki/*.md`), Mythical History (`/wiki/mythical-history.md`), and `llms.txt` so both `https://node.tevm.sh` and the in-app Docs tab on [Smithers Cloud](https://smithers.sh/evmts/tevm/docs) serve every page cleanly.
