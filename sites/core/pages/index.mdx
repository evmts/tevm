## The complete first transaction

Install `tevm` and its `viem` peer on Node.js 24+, then run:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient, parseEther, PREFUNDED_ACCOUNTS } from 'tevm'

const client = createMemoryClient({ mining: { auto: false } })
try {
  const recipient = '0x1111111111111111111111111111111111111111'

  const { txHash } = await client.tevmCall({
    from: PREFUNDED_ACCOUNTS[0].address,
    to: recipient,
    value: parseEther('1'),
    addToMempool: true,
  })

  assert.ok(txHash)
  await client.tevmMine({ blocks: 1 })

  const receipt = await client.getTransactionReceipt({ hash: txHash })
  const balance = await client.getBalance({ address: recipient })

  assert.equal(receipt.status, 'success')
  assert.equal(balance, parseEther('1'))
} finally {
  await client.tevmClose()
}
```

`tevmCall` simulates by default. `addToMempool: true` queues a pending transaction, `tevmMine({ blocks: 1 })` makes it canonical, and `tevmClose()` releases the native handle.
