## The complete first transaction

Install `tevm@1.0.0-rc.151` and its `viem` peer, then run:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient, parseEther, PREFUNDED_ACCOUNTS } from 'tevm'

const client = createMemoryClient({ miningConfig: { type: 'manual' } })
const recipient = '0x1111111111111111111111111111111111111111'

const { txHash } = await client.tevmCall({
  from: PREFUNDED_ACCOUNTS[0].address,
  to: recipient,
  value: parseEther('1'),
  addToMempool: true,
})

assert.ok(txHash)
await client.tevmMine({ blockCount: 1 })

const receipt = await client.getTransactionReceipt({ hash: txHash })
const balance = await client.getBalance({ address: recipient })

assert.equal(receipt.status, 'success')
assert.equal(balance, parseEther('1'))
```

`tevmCall` simulates by default. `addToMempool: true` turns the call into a pending transaction, and manual mining makes it canonical.
