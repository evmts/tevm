# Core API map

## Entry points

| Import | Main exports |
| --- | --- |
| `tevm` | `createMemoryClient`, `createZevmEngine`, `createTevmNode`, `NativeRpcError`, standalone `tevm*` actions, `createContract`, viem utilities, `PREFUNDED_ACCOUNTS` |
| `tevm/node` | `createZevmEngine`, `createTevmNode`, `NativeRpcError`, `ZevmEngine` types |
| `tevm/memory-client` | `createMemoryClient`, `createTevmTransport`, `tevmViemActions`, `tevmReady` |
| `tevm/actions` | Browser-safe `tevmCall`, `tevmContract`, `tevmDeploy`, `tevmDeal`, `tevmGetAccount`, `tevmSetAccount`, `tevmMine`, `tevmDumpState`, `tevmLoadState` |
| `tevm/server` | `createServer`, `createIpcServer`, `createHttpHandler`, `createWebSocketServer`, `createExpressMiddleware`, `createNextApiHandler` |
| `tevm/http-client` | `createHttpClient` |
| `tevm/common` | Viem chain presets and `tevmDefault` (`foundry`) |
| `tevm/contract` | `createContract` and bundled fixtures (`SimpleContract`, `ERC20`, `ERC721`, `ErrorContract`) |
| `tevm/utils` | Hex, bytes, ABI, RLP, signing helpers, `PREFUNDED_ACCOUNTS` |
| `tevm/bundler/*` | Solidity plugins for Vite, Rollup, esbuild, Webpack, Rspack, and Bun |

## Memory client options

```ts
import assert from 'node:assert/strict'
import { createMemoryClient, PREFUNDED_ACCOUNTS } from 'tevm'

const client = createMemoryClient({
  chainId: 31337,
  account: PREFUNDED_ACCOUNTS[0],
  mining: { auto: false },
})

try {
  await client.tevmReady()
  assert.equal(client.account?.address, PREFUNDED_ACCOUNTS[0].address)
  assert.equal(await client.getChainId(), 31337)
  assert.equal(await client.getBlockNumber(), 0n)
} finally {
  await client.tevmClose()
}
```

| Option | Type | Default |
| --- | --- | --- |
| `chainId` | `number` (unsigned safe integer) | `31337` |
| `mining` | `{ auto?: boolean; interval?: number }` | `{ auto: true }` |
| `fork` | `{ url: string; blockNumber?: number }` | `undefined` |
| `engine` | `ZevmEngine` | new isolated engine |
| `common` | viem `Chain` | `foundry` |
| `account` | viem `Account \| Hex` | `undefined` |
| `name` / `key` | `string` | `'TEVM'` / `'tevm'` |

## Return boundaries

| Operation | Returns |
| --- | --- |
| `tevmCall` (read) | `{ rawData }` (throws `NativeRpcError` with `code: 3, data` on revert) |
| `tevmCall` (`addToMempool` / `addToBlockchain`) | `{ rawData: '0x', txHash, receipt? }` |
| `tevmContract` | `CallResult & { data? }` (`data` decoded on read calls) |
| `tevmDeploy` | `CallResult & { createdAddress? }` |
| `tevmGetAccount` | `{ address, balance: bigint, nonce: bigint, deployedBytecode, storage }` |
| `tevmDumpState` | Opaque ZEVM `Hex` blob |
| `engine.request` | Parsed JSON-RPC result (hex quantities) |
| `engine.rpc` | Exact JSON-RPC wire string, or `null` for notifications |
