# State & snapshots

Voltaire and ZEVM own all account and storage state inside the native engine. Read and mutate state through `tevmGetAccount`, `tevmSetAccount`, `tevmDeal`, viem Anvil test actions, snapshots, and portable state blobs.

## Accounts, code, and storage

```ts
import assert from 'node:assert/strict'
import { createMemoryClient, toHex } from 'tevm'

const client = createMemoryClient()
try {
  const address = '0x6666666666666666666666666666666666666666'
  const slot = toHex(1n, { size: 32 })
  const value = toHex(2n, { size: 32 })

  await client.tevmSetAccount({
    address,
    balance: 10n,
    nonce: 1n,
    deployedBytecode: '0x602a60005260206000f3',
    storage: { [slot]: value },
  })

  const account = await client.tevmGetAccount({ address })
  assert.equal(account.balance, 10n)
  assert.equal(account.nonce, 1n)
  assert.equal(account.deployedBytecode, '0x602a60005260206000f3')
  assert.equal(await client.getStorageAt({ address, slot }), value)
} finally {
  await client.tevmClose()
}
```

<WatchOut title="Multi-field tevmSetAccount calls are not atomic">
`tevmSetAccount` dispatches one native RPC call per supplied field (`anvil_setBalance`, `anvil_setNonce`, `anvil_setCode`, `anvil_setStorageAt`). Take a `snapshot()` first if a multi-field update needs all-or-nothing rollback.
</WatchOut>

## Portable state blobs (`tevmDumpState` / `tevmLoadState`)

`tevmDumpState()` exports ZEVM's opaque hexadecimal state blob. Load that blob into a separate engine to clone or restore state:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient } from 'tevm'

const source = createMemoryClient()
const target = createMemoryClient()

try {
  const address = '0x7777777777777777777777777777777777777777'
  await source.tevmDeal({ address, amount: 99n })

  const blob = await source.tevmDumpState()
  await target.tevmLoadState(blob)

  assert.equal((await target.tevmGetAccount({ address })).balance, 99n)
} finally {
  await source.tevmClose()
  await target.tevmClose()
}
```

## Operation map

| Concern | Read | Write |
| --- | --- | --- |
| Full account | `tevmGetAccount` (`zevm_getAccount`) | `tevmSetAccount` |
| Balance | `getBalance` | `tevmDeal`, `setBalance` |
| Code | `getCode` | `setCode`, `tevmSetAccount` |
| Storage | `getStorageAt` | `setStorageAt`, `tevmSetAccount` |
| In-process rewind | `snapshot` (`evm_snapshot`) | `revert` (`evm_revert`) |
| Cross-engine transfer | `tevmDumpState` (`anvil_dumpState`) | `tevmLoadState` (`anvil_loadState`) |
