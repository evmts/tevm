# Memory client

`createMemoryClient` is the default interface for tests and Node.js applications. It creates an isolated `ZevmEngine` inside `createTevmTransport()` with `cacheTime: 0`, then attaches viem `publicActions`, `walletActions`, `testActions({ mode: 'anvil' })`, and `tevmViemActions()`.

## Snapshot and roll back state

Snapshots capture local state, mined blocks, and timestamps so a test can rewind cleanly without rebuilding setup:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
try {
  const address = '0x3333333333333333333333333333333333333333'
  const snapshotId = await client.snapshot()

  await client.setBalance({ address, value: 42n })
  assert.equal(await client.getBalance({ address }), 42n)

  await client.revert({ id: snapshotId })
  assert.equal(await client.getBalance({ address }), 0n)
} finally {
  await client.tevmClose()
}
```

## Deploy and call a contract

Pass `account` for a default wallet sender, and `mining: { auto: false }` when you want explicit block boundaries:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient, PREFUNDED_ACCOUNTS } from 'tevm'
import { SimpleContract } from 'tevm/contract'

const client = createMemoryClient({
  account: PREFUNDED_ACCOUNTS[0],
  mining: { auto: false },
})

try {
  const hash = await client.deployContract(SimpleContract.deploy(7n))
  await client.mine({ blocks: 1 })

  const receipt = await client.getTransactionReceipt({ hash })
  assert.ok(receipt.contractAddress)

  const contract = SimpleContract.withAddress(receipt.contractAddress)
  assert.equal(await client.readContract(contract.read.get()), 7n)
} finally {
  await client.tevmClose()
}
```

## Lifecycle reference

| Operation | Behavior |
| --- | --- |
| `createMemoryClient(options)` | Returns synchronously with an isolated native handle (or wraps `options.engine`). |
| `client.tevmReady()` | Awaits startup fork and mining configuration; rejects on setup errors. |
| `client.transport.tevm` | Underlying `ZevmEngine` (`request`, `rpc`, `events`, `ready`, `close`). |
| `client.tevmClose()` | Stops interval timers and releases native memory (also closes a supplied `engine`). |
