# Actions

Every operation in tevm can be called through a `MemoryClient` method, a standalone browser-safe function from `tevm/actions`, or a raw EIP-1193 `request()`. Pick the form that fits your bundle and call site.

| Form | Input / Output | Best fit |
| --- | --- | --- |
| `MemoryClient` method | Typed viem & `bigint` values | Applications and tests |
| Standalone `tevm/actions` | Takes any `RpcClient` (`request()`) | Tree-shaking, `ZevmEngine`, remote HTTP clients |
| EIP-1193 `request()` | JSON-RPC hex quantities | Wallets, providers, RPC tooling |

## Client actions

Public reads and TEVM helpers share one native engine:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
try {
  const address = '0x4444444444444444444444444444444444444444'

  await client.tevmSetAccount({ address, balance: 25n, nonce: 2n })

  const account = await client.tevmGetAccount({ address })
  const publicBalance = await client.getBalance({ address })

  assert.equal(account.balance, 25n)
  assert.equal(account.nonce, 2n)
  assert.equal(publicBalance, 25n)
} finally {
  await client.tevmClose()
}
```

## Standalone helpers (`tevm/actions`)

Standalone functions bind to any `RpcClient` — including a bare `ZevmEngine` with no viem client wrapper:

```ts
import assert from 'node:assert/strict'
import { tevmGetAccount, tevmSetAccount } from 'tevm/actions'
import { createZevmEngine } from 'tevm/node'

const engine = createZevmEngine()
try {
  const address = '0x5555555555555555555555555555555555555555'

  await tevmSetAccount(engine, { address, balance: 100n })
  const account = await tevmGetAccount(engine, { address })

  assert.equal(account.balance, 100n)
} finally {
  await engine.close()
}
```

## EIP-1193 `request`

`request({ method, params })` returns JSON-RPC hex quantities directly:

```ts
import assert from 'node:assert/strict'
import { createMemoryClient } from 'tevm'

const client = createMemoryClient()
try {
  const chainId = await client.request({ method: 'eth_chainId' })
  const blockNumber = await client.request({ method: 'eth_blockNumber' })

  assert.equal(chainId, '0x7a69')
  assert.equal(blockNumber, '0x0')
} finally {
  await client.tevmClose()
}
```

## Simulation, mempool, and canonical blocks

<CoreCallFlowDiagram />

| Call | State effect |
| --- | --- |
| `tevmCall(params)` | Runs `eth_call` (with optional `stateOverride`); discards state |
| `tevmCall({ ...params, addToMempool: true })` | Submits via `eth_sendTransaction`; stays pending in manual mode |
| `tevmCall({ ...params, addToBlockchain: true })` | Submits and mines a block if no receipt exists yet |
| `tevmMine({ blocks, interval })` | Mines canonical blocks via `anvil_mine` |
